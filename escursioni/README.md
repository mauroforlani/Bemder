# Escursioni

Sezione dell'Hub derivata dal progetto "Cime e rifugi": scrivi una zona, imposta la distanza (5–50 km) e premi **Cerca** per vedere le cime e i rifugi più conosciuti, con sentieri segnati e link alle relazioni (Camptocamp, Gulliver, Hikr, Vienormali, Wikiloc).

Non salva dati sul repository: interroga direttamente OpenStreetMap (Overpass, Nominatim), Photon, Wikipedia/Wikidata e Camptocamp.
